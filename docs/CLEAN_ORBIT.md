# CaldaSpace 3.2: Clean Orbit

This release is a visual reset focused on restraint and mobile composition.

## Removed from the main canvas

- Floating installation prompt
- Global network-status overlay
- Route-warp flash
- Oversized active-navigation pill
- Excessive card glow, floating and shine effects
- Animated mission badge and progress ring
- Heavy gradients on primary surfaces

## Changed

- 60 px mobile header and bottom navigation
- Compact single-line wordmark
- Smaller header controls and avatar
- Solid cyan primary action instead of repeated multicolour gradients
- Flatter dark surfaces with quieter borders and shadows
- Compact mission layout and badge
- Smaller progress ring and denser crew statistics
- Reduced page-title scale and section spacing
- Cleaner Discover, Learn, Observe and Play cards
- Installation action moved into profile settings
- Empty saved counter hidden

## Preserved

- Three.js planet and 3I/ATLAS scenes
- NASA APOD, archive and image search
- Rover gallery and NASA API-key setting
- NEO monitoring and space news
- Family profiles, saved discoveries, XP, ranks and missions
- Learning modes, theories, quiz, transit lab and achievements
- Reduced-motion accessibility
